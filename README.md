## ⚡ The Challenge: The OneDrive "Files On-Demand" Trap

Standard desktop duplicate cleaners fail on modern cloud sync roots. In Windows 11/10 and macOS, OneDrive saves physical disk space using **Files On-Demand**, representing cloud-only files as lightweight NTFS reparse stubs (0 bytes locally).

When a standard duplicate tool attempts to compute hashes:
1. It requests a read stream for every file stub.
2. The operating system forces a mass download ("rehydration") of hundreds of gigabytes from Microsoft cloud servers.
3. Local disk space exhausts immediately, saturating network bandwidth and crashing the system.

### Solution: Smart Staging & Metadata Inspection
Safe cloud deduplication reads OneDrive cloud headers and local sparse-file attributes first. It only downloads candidate data when pre-filters detect exact byte-length collisions, saving gigabytes of unnecessary network traffic.

### Why SHA-256 is the Enterprise Standard:
- **Zero Collision Risk:** $1 \text{ in } 2^{256}$ probability prevents accidental false deletions.
- **Filename Agnostic:** Accurately pairs duplicates even if they have been completely renamed (`Scan_2026.pdf` vs `Tax_Doc_Final.pdf`).

## 🖼️ Visual Perceptual Hashing (pHash) for Media Sprawl

Camera roll syncs from mobile devices often create format variations that fail binary SHA-256 matching:
- Apple HEIC converted to JPEG during Windows sync.
- Resized copies generated by messaging applications.
- Burst photos captured milliseconds apart.

The integrated **Perceptual Hashing (pHash)** engine computes a discrete cosine transform (DCT) of image luminance, generating a 64-bit structural fingerprint to detect and group visual duplicates with configurable similarity thresholds.

## 💻 PowerShell Verification Snippet

For quick manual hash comparison of individual candidate files:

```powershell
# Compute and verify SHA-256 hashes of two OneDrive files
$FileA = Get-FileHash -Path "$HOME\OneDrive\Projects\Report.xlsx" -Algorithm SHA256
$FileB = Get-FileHash -Path "$HOME\OneDrive\Archive\Copy_of_Report.xlsx" -Algorithm SHA256

if ($FileA.Hash -eq $FileB.Hash) {
    Write-Host "Files are bit-exact duplicates. Safe to consolidate." -ForegroundColor Green
} else {
    Write-Host "Files have distinct binary content. Do not delete." -ForegroundColor Red
}
